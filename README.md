Token Radar Senja — a fitted launch-value board: every pre-token protocol in the snapshot ranked by an implied value fitted from its token-bearing peers (log mcap on log TVL, per-category intercepts, held-out tested), with token odds from the peers' listing record and a costed, netted farm plan per row. Senja is dusk in Indonesian — the hour before a launch.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input /path/to/snapshot.json
```
